Minecraft Mod Manager

A security-focused Minecraft mod management application for private home servers.

Features

  • Installed mod inventory
  • Modrinth update discovery
  • Version and dependency checking
  • Verified staging downloads
  • CurseForge integration (in development)

Security

Administration is restricted to local access through SSH tunneling. No public management endpoint is exposed.

Project Status

Personal, non-commercial, active development.
